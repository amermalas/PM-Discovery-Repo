# Repo Map Template

This skill assumes you will point it at your own evidence corpus and prior studies. Fill this in once for your own workspace so the skill can cite concrete sources instead of generic prose.

```text
Customer/account evidence corpus: <where you keep account reports, support notes, survey rows, etc.>
Competitor-mention signal: <how competitor mentions/switching signals show up in that corpus>
Your product's verified capability source: <feature docs, API docs, internal capability map>
Prior competitive studies / dossiers to reuse: <paths, if any>
Landscape-building script: <a script that turns raw evidence rows into a competitor x arena table, once you have one>
Scoring-matrix script: <a script that builds the scoring matrix + composites, once you have one>
Chart-building script: <a script that renders the standard chart set, once you have one>
Report-building script: <a script that renders shareable reports from findings, once you have one>
Change-log location: <where you note "a competitive study was run/updated">
```

Keep this file local to your own fork if the concrete paths are private; the public version of this skill intentionally ships without example values.
