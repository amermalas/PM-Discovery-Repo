# Security & Sensitive-Content Policy

This repository is a public, public-safe skill package. Its primary risk is the accidental inclusion of private or sensitive content. This policy covers both that and conventional security issues.

## What to report

Please report, privately, if you find any of the following in this repository:

- customer data, personal data, or real company/product names;
- internal source IDs, private URLs, local file paths, or proprietary assets;
- secrets, tokens, or credentials;
- or a conventional security vulnerability.

## How to report

Report privately — **do not open a public issue or pull request** for sensitive content.

- **Preferred:** use GitHub's private vulnerability reporting for this repository (the **Security** tab → **Report a vulnerability**), which keeps the report confidential.
- If that is unavailable, contact the repository owner privately through GitHub.

When reporting, describe *where* the problem is rather than pasting the sensitive content itself, so it can be removed and the history scrubbed if needed.

## Response

Reported sensitive content will be removed promptly, and repository history will be rewritten if the content was committed. Conventional issues will be triaged and addressed as appropriate for a template/content repository.

## Scope

This repo contains documentation, skill definitions, and templates — there is no runtime service here. The safety surface is the content itself.
